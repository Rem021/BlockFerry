# 产品设计

## 一句话定位

BlockFerry 是“Minecraft 个人设置的版本控制与跨启动器迁移器”。

它服务的不是整合包作者发布内容，而是玩家在更新整合包、换启动器、换电脑时保留自己的手感、知识库和选择。

## 三层数据模型

### 我的习惯

默认允许迁移：

- 语言、按键、鼠标、视野、GUI、音量、聊天与辅助功能；
- JEI / REI / EMI 收藏、查询历史和用户过滤；
- 模组启用/禁用选择；
- 地图航点；
- 服务器列表（需显式开启）。

### 整合包资产

默认保护，除非适配器能证明可安全合并：

- 新版模组 JAR、KubeJS/CraftTweaker 脚本；
- 默认配置、资源包默认顺序、数据包；
- 整合包作者提供的菜单、任务和材质。

### 本机设置

按设备保存，默认不跨电脑：

- Java 路径、内存与 JVM 参数；
- 窗口大小、显卡与渲染设备选择；
- 启动前后命令和本机目录。

## 核心流程

1. 自动扫描并推荐最可能的旧实例与新实例；置信度不足时才让用户选择。
2. 应用窗口打开后直接进入连续版本场景：左侧展示“从 r19 / 到 r20”，右下显示巨型“20”，底部操作区提供来源上下文、状态、详情和唯一主按钮 `ArrowRight + 同步到 r20`；没有配置向导、实例卡墙、侧栏或页脚。
3. 点击后在同一状态区依次执行“检查实例 → 创建还原点 → 迁移设置 → 验证结果”四步。安全项目不中断；只有冲突或硬性阻止条件才弹出精简处理层，并默认推荐最安全操作。
4. 完成态在原状态区直接变为“完成”；查看结果、撤销和首次退出后的护盾复核按需或自动进行，不新增完成页、重复确认或 Toast。

## 首次运行护盾

“必须先启动新版”不是正常前置条件，而是要由产品吸收的初始化时序：

- 启动器仍在导入时，等待实例元数据和文件稳定，而不是提前写入；
- 对安全且格式确定的文件，BlockFerry 直接创建目标目录和内容；
- 在首次启动前记录受保护用户状态；
- 游戏退出后检测启动器或模组的首启覆盖，只恢复被覆盖的用户字段；
- 只对确实必须由游戏生成的未知结构使用退出后续写，并在 UI 中明确说明。

## 默认同步范围

首次使用不要求玩家理解或选择多个配置档。安全默认项包含语言、按键、鼠标、视野、GUI、音频、辅助功能、JEI 收藏/历史和模组启停。

服务器列表、世界存档、大型地图数据、资源包大文件和本机 Java/内存参数默认不迁移，只在“查看详情”中明确开启。高级规则作为后续能力，不在主窗口常驻。

## 冲突体验

默认界面不展示三栏差异表。已自动处理内容折叠为“已安全处理 N 项”；只有未解决项目进入冲突卡：

- 绿色：可自动合并；
- 灰色：目标不存在对应项目，安全跳过；
- 琥珀色：多候选或双方同时修改，等待选择；
- 红色：会破坏依赖、目标正在运行或验证失败，禁止执行。

每个冲突使用一句人话解释影响，只提供一个推荐操作和“其他选择”。路径、哈希与原始字段收进“技术详情”。用户的选择可以保存为仅本次、此整合包或全局规则。

## 视觉与动效

视觉定位是安静、清晰且有版本辨识度的独立桌面工具：借鉴 Apple 的内容优先、WinUI 的 Mica/Acrylic 分层、Raycast/Linear 的低干扰与 LauncherX 的版本表达。一个任务只用一张整窗连续场景画布；左侧编辑式迁移文案、右下巨型版本数字和底部操作区构成唯一主界面，不使用实例卡墙、网页页脚或多层玻璃。只学习设计原则和动效节奏，不复制任何第三方品牌、图标、素材与逐像素布局。

参考基线包括 [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Apple Migration Assistant](https://support.apple.com/guide/mac-help/transfer-information-mac-computer-device-mh27921/mac)、[WinUI 现代桌面应用结构](https://learn.microsoft.com/en-us/windows/apps/develop/ui/windows-app-sdk-app-structure)、[Windows Mica/Acrylic](https://learn.microsoft.com/en-us/windows/apps/get-started/best-practices)、[Raycast Settings](https://manual.raycast.com/settings)、[Linear UI redesign](https://linear.app/now/how-we-redesigned-the-linear-ui)、[LauncherX 宣传片](https://www.bilibili.com/video/BV1Tw5SzKEpi/) 与 [LauncherX 官方产品页](https://corona.studio/lx)。交接包只保存链接和本项目自产预览，不包含第三方视频或截图。

视觉基线：

- 展示字、正文、辅助文字和普通控件使用 Windows 系统字体栈，优先 Segoe UI Variable 与 Microsoft YaHei UI；公开源码和构建不分发第三方字体文件；
- 默认窗口约 980 × 640；场景标题 15 px、编辑式版本字 38–56 px、整合包名称 20–22 px、正文 12–15 px、主按钮文字至少 15 px；
- 主界面是覆盖完整可用窗口的连续场景画布，不使用来源/目标卡片、路线列表或会形成上下空块的外层主容器；
- 左侧编辑式展示区直接表达“从 r19 / 到 r20”、整合包名称和迁移目的；底部操作区只保留 `r19 来源`、同步状态、运行时进度、详情入口和唯一 CTA；
- 右下巨型半透明“20”使用绝对定位、`aria-hidden`、不参与布局和命中测试，并允许被窗口边缘裁切；正文、状态和交互始终在其上方；
- 功能图标为 22–28 px、stroke 不低于 2.4；交互目标至少 44 × 44 px，主按钮使用 14–16 px 圆角；
- 中性低噪背景只配一个品牌强调色；绿色、琥珀色与红色只表达成功、冲突与危险；
- 顶栏与底部操作区删除硬边和矩形底座，使用带方向蒙版的渐隐毛玻璃融入场景；Drawer 保留一层受控模糊，并提供不透明渐变降级；
- 层级主要依靠字号、字重、留白、明度和一个共享表面，不堆叠细边框、霓虹辉光、多色渐变或重复状态胶囊；
- 空闲态直接显示文字状态；运行时才出现 spinner 与进度条，完成时在同一位置显示勾选和“完成”，不弹 Toast；
- 主按钮使用向右迁移箭头与“同步到 r20”，不得使用容易被理解为启动游戏的 Play 图标；
- 深色与浅色主题共用同一组语义 token；首次打开跟随系统，用户点击后在本机记忆选择。主题只有一个太阳/月亮切换入口；顶栏另有设置图标占位，当前不打开设置页；
- 字体使用清晰粗体层级，版本字、整合包名称、状态和主按钮不得依赖低对比细字表达关键信息；
- 顶栏、底部操作区与 Drawer 使用受控模糊，减少透明度时全部切换为不透明渐变或表面；
- 保留现有 Drawer 尺寸策略：桌面右侧 Drawer 宽度上限 400 px，窄屏为全宽 Sheet；开启、关闭和内部滚动不能改变主窗口或文档尺寸。
- 构建必须复制运行时与第三方组件的 `THIRD-PARTY-NOTICES.txt`；缺失 notice 的产物不得交付。

动效只解释状态：

- 160 ms：按钮、开关和 hover 微交互；
- 240–280 ms：状态变化与列表重排；
- 220–320 ms：窗口内 Drawer、冲突层和操作区状态转场；
- 使用克制的 spring / ease-out，普通位移不超过 12 px、缩放不超过 1.02；
- 工作区入场、巨型“20”揭示、按钮 hover/按下、同步版本字与进度、原位完成、Drawer、主题颜色与太阳/月亮图标使用状态动画；背景景深光允许 9 秒往返的极慢漂移，实际同步中的 spinner/进度允许循环，减少动态时两者都必须停用；
- 删除常驻星尘、轨道、漂浮、扫光和循环霓虹脉冲。

当前 Web 原型验收基线为 980 × 640、884 × 816 与 390 × 844：三种尺寸都保留同一连续场景、左侧编辑式版本表达和右下巨型“20”；窄屏只重新排列底部操作区，不转换成卡片或列表。深/浅主题、Drawer、运行态与原位完成态均无布局回归，Drawer 打开前后自身、窗口和文档尺寸不变。减少动态时取消位移、旋转、缩放和循环，减少透明度时关闭景深光与模糊并使用不透明表面。正式 WinUI 还必须覆盖 1366 × 768、1920 × 1080、100/125/150% 缩放、键盘导航、高对比度与可读焦点环，不能出现裁字或横向溢出。当前 UI 仍使用演示数据，不代表真实适配器或事务写入已经完成。

## 路线图

### 0.1

PCL2 与 Prism/MultiMC 完整适配、HMCL Beta、任意目录、单向迁移、options、JEI、模组启停、首次运行护盾、预览/备份/验证/回滚。Modrinth 与 CurseForge 先使用不写私有元数据的目录模式。

### 0.2

REI/EMI；Xaero/JourneyMap；资源包/光影选择；配置档与托盘模式；NAS/SMB 配置胶囊；扩大 HMCL 自动发现覆盖。

### 1.0

Modrinth、CurseForge、ATLauncher；WebDAV/OneDrive；多设备双向同步；历史时间线；规则模板；MSIX 与便携版。

### 后续

签名适配器目录、端到端加密、家庭成员配置、整合包作者推荐迁移规则、兼容度评分。
